# 绘制编辑工具（Editor）

本示例演示 `mapv-three` 的 `Editor` 绘制/编辑能力：在地图上绘制多边形、线、点、圆、矩形等要素，支持样式配置、要素编辑、显隐管理与数据导入/导出。

## 效果与功能点

- **多类型绘制**：`POLYGON / LINE / POINT / CIRCLE / RECTANGLE`。
- **连续绘制**：开启后可连续创建要素。
- **样式配置**：填充色/透明度、描边色/宽度/透明度，点半径、圆半径等。
- **编辑模式**：进入编辑后可对已有要素进行编辑（可退出编辑模式）。
- **图层管理**：按要素类型统计数量、单独显隐、批量删除。
- **数据导入/导出**：导入 `.json`（GeoJSON 风格数据），导出全部或按类型导出。

## 交互说明

- **开始/停止绘制**：选择绘制类型与样式后开始绘制；可随时停止。
- **进入/退出编辑**：进入后点击要素进行编辑；退出恢复普通交互。
- **中点标记**：可切换是否启用中点控制点（会重建 `Editor` 并恢复已绘制数据）。
- **导入/导出**：导入会清空并覆盖当前数据；导出会下载为本地 JSON 文件。

## 目录结构与关键文件

- `index.jsx`：页面入口
- `Editor.jsx`：核心实现（`Editor` 初始化、事件监听、样式与面板交互、导入导出逻辑）
- `Editor.less`：样式
