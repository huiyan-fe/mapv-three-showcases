# 测量工具（Measure）

本示例演示 `mapv-three` 的 `Measure` 测量能力：支持距离测量、面积测量与坐标测量，并提供样式配置与结果清除等交互。

## 效果与功能点

- **距离测量**：绘制折线并实时输出距离结果。
- **面积测量**：绘制多边形并计算面积，支持填充/描边样式。
- **坐标测量**：点击/取点获取坐标信息。
- **连续测量**：支持持续创建多个测量结果。
- **样式配置**：线色/线宽、填充色/透明度（按测量类型启用）。
- **一键清除**：清空全部测量结果。

## 交互说明

- **选择测量模式**：距离 / 面积 / 坐标（三选一）。
- **开始测量**：进入测量状态并在地图上进行绘制/取点。
- **连续测量**：开启后完成一次测量会自动准备下一次测量。
- **停止测量**：退出测量状态。
- **清除所有测量**：清空当前所有测量图形与结果。

## 目录结构与关键文件

- `index.jsx`：页面入口
- `Measure.jsx`：核心实现（`Measure` 初始化、样式同步、事件监听与面板交互）
- `Measure.less`：样式
