# 卫星轨道可视化（Satellite）

本示例演示在地球坐标系（ECEF）下渲染卫星与轨道：读取本目录 `assets/gps.txt` 的 TLE 数据，创建卫星对象并计算轨道线；在渲染循环中推进时间、更新卫星位置，并用点与文字标注展示卫星的实时位置与名称，同时提供“时间流速”滑块控制。

## 效果与功能点

- **TLE 解析**：从 `assets/gps.txt` 读取文本并按三行一组解析为 TLE。
- **卫星与轨道线**：使用 `satellite.js`（`SatelliteObject`）创建卫星实体，并生成轨道折线数据。
- **ICRF -> 固定坐标系转换**：在每帧渲染前将卫星位置从惯性系转换到固定系，用于正确渲染到场景中。
- **点与文字标注**：
  - `SimplePoint`：绘制卫星当前位置点
  - `Text`：绘制卫星名称
- **时间流速控制**：自定义 DOM 滑块写入 `window.timeFlowRate`，用于控制时间推进速度。

## 交互说明

- **拖动滑块**：调整时间流速（从 10 秒到 5 分钟每“帧”的推进量），卫星运动速度会随之变化。

## 目录结构与关键文件

- `index.jsx`：页面入口（设置 `window.CESIUM_BASE_URL`）
- `Satellite.jsx`：核心实现（UI 滑块、时间推进、位置更新与标注渲染）
- `satellite.js`：卫星对象与轨道相关逻辑
- `assets/gps.txt`：TLE 数据文本
