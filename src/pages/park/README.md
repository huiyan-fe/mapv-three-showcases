# 登山路线与跟随漫游（Park）

本示例演示在三维地球场景中绘制多条登山路线，并使用 `PathTracker` 让一个带动画的 3D 角色模型沿路径移动，同时支持路线切换、线动画高亮、以及“爬山/停止”两种整体状态。

## 效果与功能点

- **路线渲染**：多条路线以 `GroundObject(Line)` 方式绘制，支持开启/关闭线动画高亮。
- **路线总览**：额外渲染一条“粗线总览”（`Polyline`），用于爬山状态下统一展示。
- **路径跟随**：使用 `PathTracker` 让 `AnimationModel` 沿路线运动，并锁定视角跟随。
- **标注与引导**：通过 `Polyline/Text/SimplePoint/Icon` 组合绘制垂直引导线、文字、点与起终点图标。

## 交互说明

- **滑块切换路线**：选择第 N 条路线后，高亮该路线的动画效果。
- **重置**：关闭所有路线高亮并清空选中。
- **爬山**：进入漫游模式（显示总览线、启动跟随、隐藏标注与分路线）。
- **停止**：退出漫游模式（停止跟随、恢复标注与分路线，并回到默认视角）。

## 目录结构与关键文件

- `index.jsx`：页面入口
- `Park.jsx`：核心实现（路线/标注绘制、`PathTracker` 跟随逻辑、UI 控制）
- `config.js`：路线与标注配置（`routeList` / `pointArr` 等）
- `assets/`：起终点图标与角色模型（如 `man_animate.glb`）
- `Park.less`：样式
