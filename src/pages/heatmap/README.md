# 热力图与热力柱（Heatmap）

本示例演示基于同一份点数据，分别以 **2D 热力图**、**3D 热力图**、**热力柱**、**热力锥** 四种方式进行可视化渲染，并支持在 UI 中一键切换渲染模式。

## 效果与功能点

- **多模式渲染**：
  - `Heatmap`：2D 热力图
  - `Heatmap3D`：3D 热力体
  - `Pillar`：柱状热力（圆柱）
  - `Pillar(shape="cone")`：锥状热力
- **数据驱动**：使用 `JSONDataSource` 读取 `mock.json` 并映射属性：
  - `count`：用于热力权重（由 `num` 映射）
  - `height`：3D/柱体高度（按 `num` 放大）
  - `size`：点半径/柱体半径（按 `num` 约束到区间）
- **主题样式**：通过 `setMapStyle(...)` 设置地图整体主题（天空/底色/样式）。

## 交互说明

- **模式切换**：点击顶部按钮切换 2D / 3D / 柱 / 锥；切换时会移除旧覆盖物并创建新覆盖物。

## 目录结构与关键文件

- `index.jsx`：页面入口
- `Heatmap.jsx`：核心实现（引擎初始化、数据源定义、模式切换与覆盖物创建/销毁）
- `mock.json`：示例点数据
- `Heatmap.less`：样式
