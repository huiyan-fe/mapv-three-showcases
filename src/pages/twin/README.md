# 孪生车流可视化（Twin）

本示例演示如何基于 `@baidumap/mapv-three` 的 `Twin` 能力，将“车流轨迹帧数据”以 3D 车辆模型的形式在地图场景中进行回放与交互（点击选车、跟车视角、车型筛选、标签/配色切换等）。

## 效果与功能点

- **车流回放**：以固定时间间隔推送帧数据，驱动车辆在场景中运动。
- **3D 车辆渲染**：按车型选择不同模板模型（轿车/卡车），支持统一变更车身颜色。
- **车辆标签**：支持显示速度 / 显示车牌 / 隐藏标签三种模式。
- **交互拾取**：点击车辆可选中并展示详情信息（车牌、车型、速度等）。
- **跟车视角**：对选中车辆开启追踪（跟随相机），并可随时取消追踪。
- **车型筛选**：按车型开关可见性，便于观察不同车辆群体。

## 快速开始

1. 确保已在项目根目录配置百度地图 AK（环境变量 `VITE_BAIDU_MAP_AK`）。
2. 启动项目后进入本示例页面（具体路由以项目导航为准）。

> 本示例会使用 Bing 影像作为底图瓦片（`BingImageryTileProvider`），请确保网络环境可访问。

## 交互说明

- **播放 / 暂停**：控制帧数据持续推送与回放。
- **重置**：回到第 0 帧并清空选中车辆；若处于暂停状态会自动恢复播放。
- **车身颜色**：切换后会立即推送当前帧刷新车辆外观。
- **标签显示**：
  - 显示速度：标签展示 `xx km/h`
  - 显示车牌：标签展示 `plateno`
  - 隐藏标签：关闭标签对象可见性
- **车型筛选**：勾选开关控制不同 `modelType` 的车辆显隐。
- **车辆追踪**：
  - 点击车辆后，使用“跟车视角”开启追踪
  - “取消追踪”恢复自由视角

## 数据与渲染逻辑（要点）

- **数据来源**：`data/twin.json` 为按帧组织的车流数据（每帧包含 `tracks`）。
- **推送方式**：使用定时器按 200ms 推送一帧到 `twin.push(tracks)`。
- **字段处理**：通过 `twin.dataProvider.process(...)` 将原始字段映射为渲染所需属性：
  - `time`：使用 `timestamp` 驱动时间线（推送时写入 `Date.now()`）
  - `point`：`[x, y, 0]`
  - `dir`：由 `heading` 转换得到弧度方向
  - `speed`：速度取整（用于标签显示）
  - `modelType`：示例中用 `id` 奇偶映射为轿车/卡车（可按需替换为真实车型字段）
  - `color`：由 UI 选择的颜色预设决定
  - `plateText`：根据“标签显示”模式返回车牌或速度文本

## 目录结构与关键文件

- `index.jsx`：页面入口
- `Twin.jsx`：核心实现（地图引擎、Twin 对象、数据推送、UI 交互）
- `Twin.less`：样式
- `data/twin.json`：示例车流帧数据

## 常见问题

- **看不到车辆/不动**：确认 `VITE_BAIDU_MAP_AK` 已正确配置，且 `data/twin.json` 中首帧存在 `tracks` 并包含 `x/y/heading` 等字段。
- **底图不显示**：本示例使用 Bing 影像，若网络受限可替换为其它影像 provider。
