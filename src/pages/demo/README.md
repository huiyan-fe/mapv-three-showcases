# Demo（最小示例）

本示例提供一个最小可运行的 `mapv-three` 用法：创建 `Engine`，并在场景中添加一个 `Marker` 作为覆盖物示例。

## 效果与功能点

- **引擎初始化**：在容器节点上创建 `Engine`。
- **添加覆盖物**：添加一个 `Marker`，并使用本目录（或项目静态资源）中的图片作为图标。

## 目录结构与关键文件

- `index.jsx`：页面入口
- `Demo.jsx`（位于 `index.jsx` 同级文件中直接实现）：创建 `Engine` 并添加 `Marker`

## 常见问题

- **看不到标注**：检查图标资源路径是否可访问，或确认地图视野是否覆盖到标注坐标点。
