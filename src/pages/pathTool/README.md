# 轨迹视频导出工具（PathTool）

本示例演示一个“从地图轨迹生成视频”的完整流程：在地图上绘制/编辑轨迹（或导入/粘贴轨迹），用 `PathTracker` 或 `HorizontalOrbitTracker` 预览相机运动，再通过 `engine.renderVideo(...)` 渲染出帧序列，并用 `@ffmpeg/ffmpeg` 在浏览器端合成为视频文件。

## 效果与功能点

- **轨迹获取**：
  - 绘制折线轨迹（`Editor.DrawerType.LINE`）
  - 导入 `.json/.geojson`（提取第一条线）
  - 从剪贴板粘贴轨迹坐标数组
- **轨迹编辑**：支持启用编辑模式修改折线形状。
- **旋转拍摄**：选择一个旋转中心点（`Editor.DrawerType.POINT`），用 `HorizontalOrbitTracker` 做环绕拍摄。
- **预览**：根据配置启动/停止预览（相机跟随或环绕）。
- **视频渲染**：
  - `VideoConfig` 计算总帧数并回调渲染进度
  - 渲染完成后将帧 PNG 写入 ffmpeg 虚拟文件系统
  - 执行 ffmpeg 合成视频（输出到目录并提示完成）
- **底图与投影切换**：支持在 UI 中切换底图类型与投影方式（会写入本地存储并刷新页面生效）。
- **本地持久化**：轨迹、旋转中心、视野参数、部分配置会保存到本地存储，刷新后可恢复。

## 交互说明（高频操作）

- **绘制轨迹**：开始绘制后在地图上画折线；完成后会保存为 `pathData`。
- **编辑轨迹**：进入编辑后拖拽节点，编辑结束会自动保存。
- **导入/粘贴轨迹**：导入 GeoJSON 或直接粘贴坐标数组，自动更新编辑器显示。
- **预览/停止预览**：按当前模式（跟随/环绕）启动或停止相机运动。
- **渲染视频**：根据面板设置开始渲染，弹窗展示帧进度与 ffmpeg 合成进度；可取消。

## 目录结构与关键文件

- `index.jsx`：页面入口
- `PathTool.jsx`：核心实现（Editor/Tracker 初始化、预览与渲染、ffmpeg 合成）
- `PathToolPanel.jsx`：左侧配置面板
- `VideoRenderProgress.jsx`：渲染进度弹窗
- `storage.js`：本地存储读写与默认配置
- `PathTool.less`：样式
