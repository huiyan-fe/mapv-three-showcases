# 路线规划（RoutePlanning）

本示例演示 `mapv-three` 内置路线服务的使用方式：在 UI 中选择起终点与出行方式（步行/驾车/骑行/公交），调用对应的路线搜索服务进行检索，并将结果渲染到地图与侧边栏列表中，支持查看详细步骤与切换方案。

## 效果与功能点

- **多出行方式**：`WalkingRoute / DrivingRoute / RidingRoute / TransitRoute` 四种服务。
- **起终点选择**：通过 `AutoComplete` 选择示例 POI（本示例使用内置 mock 数据）。
- **路线搜索**：调用 `routeService.search(startCoords, endCoords, { alternatives: true })` 获取路线。
- **结果展示**：
  - 侧边栏展示多条方案（时间/距离/费用等）
  - 支持点击方案切换高亮（示例预留扩展）
  - “查看详情”弹窗展示逐步导航指引
- **地图清理**：切换搜索前会调用各服务的 `clearMap()` 清理之前的渲染结果。

## 交互说明

- **选择出行方式**：点击顶部按钮切换公交/驾车/步行/骑行。
- **输入起终点**：需从下拉列表选择（用于拿到坐标）。
- **交换起终点**：一键互换并在已有结果时自动重新搜索。
- **搜索路线**：执行检索并在侧边栏生成方案列表。
- **查看详情**：弹窗查看路线步骤，可直接选择该路线方案。

## 目录结构与关键文件

- `index.jsx`：页面入口
- `RoutePlanning.jsx`：核心实现（路线服务初始化、搜索与结果格式化、UI 交互与详情弹窗）
